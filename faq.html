Frequently Asked Questions

GenesisDM: Fantasy Assistant is an early Windows trial for local-first tabletop play. Here is what is implemented, what setup requires, what uses the network, and what is still planned.

The short version: this is a working early trial, not a finished commercial product. Local speech/LLM features require setup; Ollama must be installed separately for local AI. Obsidian vault browsing is available today. Some capabilities remain experimental or planned; read the requirements and privacy boundaries below before installing.

Getting Started

What do I need to run it?
OSWindows 10 or 11 only — this build is Windows-only for now
RAM8 GB minimum, 16 GB recommended (the local LLM and speech models both need headroom)
Disk spaceAllow about 6 GB free for the app and first-run model downloads; actual use varies by version and models.
GPUNot required — everything runs on CPU by default
MicrophoneOptional — only needed for live voice transcription; text-only play works fine without one
Is Ollama required? Does GenesisDM install it?

Ollama is required for GenesisDM's local LLM features, including AI scene/entity extraction. Ollama is a separate local LLM runtime that you install yourself from https://ollama.com/download. GenesisDM checks whether Ollama is installed and responding, then downloads its configured model if needed; it does not install or update Ollama for you. If you install Ollama while GenesisDM is open, return to the setup step and click Retry. If it is installed but not responding, start Ollama and click Retry. You can skip setup, but LLM-dependent features will not be ready until Ollama and its model are available.

What happens during first-run setup, and how long does it take?

After you install Ollama, GenesisDM downloads the configured LLM model, a local speech-to-text model (Whisper), and embedding models for asset search and optional speaker recognition. Budget 10–20 minutes on a typical connection; slow connections or large model downloads can take longer. The steps can be skipped and revisited by reopening setup. A microphone is optional. Setup downloads require internet. After setup, local inference can run without a cloud AI API, but optional update checks, feedback, and remote-player networking still use the network.

Do I need an internet connection?

Yes, for initial model downloads. Local speech transcription and LLM inference do not need a cloud speech or LLM API after setup. GenesisDM checks for updates over the network by default (turn this off or check manually in Settings → General → Updates). Sending feedback opens a Google Form only when you choose to submit it. Remote-player networking connects only when you opt in to a remote-play method.

Is this free? Are there any API costs?

The current trial has no subscription or per-request cloud AI API charges. Speech transcription and LLM inference run locally using Whisper and Ollama; Ollama is installed separately. First-run downloads, automatic update checks, user-initiated feedback, and optional remote play can use the network. See the privacy answer for details.

How long is the trial, and what happens when it ends?

Wave 1 is a 30-day trial from your first launch. You'll see a "Trial: N days left" label the whole time, a one-time heads-up at 3 days remaining, and a lock screen once it expires. This is a soft, local-only check — not DRM — and your saved data isn't deleted when the trial ends.

Privacy & Multiplayer

Does my voice or creative data leave my computer?

Voice transcription and LLM inference are local by default: narration is not sent to a cloud speech or LLM API when the configured Ollama host is on this computer. “Local AI” does not mean every feature is offline. Initial setup downloads models; automatic update checks contact GitHub by default (disable in Settings → General → Updates); and Send Feedback opens a Google Form in your browser only when you choose it. The optional diagnostic summary is copied for you to review and submit, not uploaded automatically. Same-Wi-Fi player sessions stay on your local network. If you opt in to Cloudflare Tunnel for remote players, that player traffic routes through Cloudflare; WireGuard is the self-hosted alternative. An Obsidian vault is selected locally; GenesisDM reads notes and writes only inside its app-owned folder. If you configure a remote Ollama host, prompts sent to that host leave this computer and are handled under that server's privacy terms.

What does a player need to join as a Player Companion?

On the same Wi-Fi, players need only a browser, your room code or QR code, and a display name — no account or app install. For players outside your network, the recommended route is the DM's opt-in Cloudflare Tunnel. Remote player traffic routes through Cloudflare; the live link is a secret, not an account login, and anyone with the link can reach the room until it closes (the room code is still required to join). WireGuard is available as a self-hosted alternative if you do not want player traffic routed through Cloudflare. Both remote routes require the DM to opt in.

Features & Limitations

Is Campaign Crafter ready to use?

It's real and working today — voice-driven entity extraction, a living storyboard with auto-drawn relationships, Scenes & Threads, and one-click run-sheet export all function. But it's the newest part of GenesisDM and still finding its final shape. Treat it as an early look rather than a finished feature, and expect rough edges.

What is supported today, planned, or still limited?
  • Custom asset libraries are supported: use Settings → Data & Storage to choose an assets folder; add your own images, music, and maps; tag assets; and rebuild the local search index. The trial ships a small redistributable scene/music starter pack, not creators' paid or personal-use libraries.
  • Obsidian is supported today: connect a local vault to browse/search notes, follow wikilinks, and add manual session logs. Session recaps, character sheets, and Campaign Crafter exports can be written inside the app-owned vault folder. Notion is planned but not built; other note-service destinations are not currently available.
  • Ollama is a separate prerequisite for local LLM features. Install it yourself; GenesisDM checks for it and downloads its model, but does not install or start the runtime.
  • Full multi-phone voice (each player's own phone mic captured with pinpoint speaker attribution) is still waiting on one remaining manual step — a TLS certificate for secure browser microphone access. It works today on a single machine; broader multi-device testing is still in progress.
  • Windows SmartScreen will likely show "Windows protected your PC" on first run, since this build isn't code-signed yet. This is expected — click "More info" → "Run anyway."
What tabletop systems does it support?

The current build includes D&D 5e (2024), Daggerheart, and a system-agnostic Generic mode. Other systems may work with Generic tools but have not necessarily received dedicated rules support.

Feedback

How do I give feedback or report a bug?

The app has an in-app Send Feedback button (always available, not just at trial's end) that opens a short pre-filled form. There's also a Copy Diagnostic Summary button that copies a plain-text summary of your most recent session to your clipboard, so you can paste it into the form yourself — no raw logs or file uploads required. There's no separate public bug tracker for this wave; the feedback form is where reports go.

Read before installing

Setup & privacy, plainly stated.

GenesisDM is a Windows desktop app with local AI features. The local-first design matters for creative work, but it does not mean every feature is offline or that no external service is ever contacted. Here are the prerequisites and boundaries.

Ollama is a separate prerequisite for local LLM features. Install it yourself from https://ollama.com/download. GenesisDM checks that it is installed/responding and can download the configured model; it does not install or update Ollama. If it was installed while GenesisDM was open, click Retry in setup.

What you need

Windows PC

  • Windows 10 or 11, 64-bit.
  • 8 GB RAM minimum; 16 GB recommended.
  • Allow about 6 GB free for the application and first-run model downloads; actual storage use varies.
  • A GPU is not required. A microphone is optional unless you want live voice transcription.

First-run downloads

  • Install and start Ollama; GenesisDM then pulls its configured local LLM model.
  • The setup wizard downloads the Whisper speech model and embedding models for asset search and optional speaker recognition.
  • Plan for 10–20 minutes on a typical connection. Slow connections or model downloads can take longer.
  • Steps can be skipped. AI features that depend on a skipped runtime/model may not work until setup is completed.

What stays local, and what can use the network

Local AI by default

Speech transcription uses the local Whisper model. LLM inference uses the configured Ollama host; the default host is the local computer. With that default, narration is not sent to a cloud speech or LLM API. If you deliberately configure a remote Ollama host, prompts sent to that server leave this PC and are subject to that server's privacy and access controls.

Setup & updates

Initial setup downloads models over the internet. Automatic release checks are enabled by default and contact GitHub; you can disable them or check manually in Settings > General > Updates. Update checks do not upload your campaign notes or narration.

Feedback is your choice

Sending feedback opens a Google Form in your browser. GenesisDM does not submit a report automatically. The optional diagnostic summary is copied to your clipboard for you to inspect and decide whether to paste into the form.

Player networking is opt-in

Same-Wi-Fi sessions connect on your local network. If you enable Cloudflare Tunnel for remote players, player traffic routes through Cloudflare; the temporary join link is a secret, not an account login. WireGuard is the self-hosted alternative. Remote play is not required for local use.

Obsidian stays a local-folder integration

You choose a vault folder on the computer. GenesisDM reads notes locally and restricts its writes to the app-owned folder inside that vault. Connecting a vault does not sync it to GenesisDM or a GenesisDM server. See Integrations for exactly what works.

Your media has its own license

The trial includes a small redistributable starter pack. Your custom assets stay in your selected local library. Paid or personal-use artwork/music must be used and transferred according to its creator's license; do not add it to public releases or shared repositories.

Setup recovery

  1. Install Ollama from ollama.com/download.
  2. Keep GenesisDM open, return to its Ollama setup step, and press Retry. The check accepts a responding configured server even if Windows has not refreshed this process's PATH.
  3. If Ollama is installed but does not respond, start Ollama from Windows and press Retry again.
  4. If you skip setup, reopen/replay setup later. For a full list of requirements and current limitations, read the FAQ.
